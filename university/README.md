# 高校分数线数据可视化分析
> 🎓 Python毕业设计 | Pandas + Matplotlib + Pyecharts(ECharts)

## 📖 项目简介
采集多所高校历年录取分数线，完成数据清洗、统计分析，生成静态图表与交互式可视化网页，用于分析院校、专业分数线变化趋势，为高考志愿填报提供参考。

## ✨ 功能清单
1. ✅ 数据集构建与导出CSV
2. ✅ Pandas数据清洗（去重、缺失值过滤、异常分数剔除）
3. ✅ Matplotlib静态折线图，展示历年分数趋势
4. ✅ Pyecharts生成交互式ECharts网页图表
5. ✅ 分组统计，输出各院校平均分
